# liftoff

Mission control for your GitHub Actions.

This project currently has one package:

- [domain](./packages/domain/README.md)

## Setup

### Install dependencies

```bash
pnpm install
```

### Testing

```bash
# Run all unit tests
pnpm test:unit
```

### Linting & formatting

```bash
pnpm lint
```

```bash
pnpm format
```

### Build

```bash
pnpm build
```
